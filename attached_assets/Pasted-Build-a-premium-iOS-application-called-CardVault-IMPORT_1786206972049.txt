Build a premium iOS application called CardVault.

IMPORTANT:
This is NOT a banking app, fintech dashboard, expense tracker, or payment app.

CardVault is a luxury digital card vault that allows users to store and instantly access cards such as:
- Library Cards
- Student IDs
- Gym Membership Cards
- Loyalty Cards
- Club Membership Cards
- Parking Cards
- Insurance Cards
- Credit/Debit Cards (view-only reference)

The design should feel like a combination of:
- Apple Wallet
- CRED
- Arc Browser
- Linear
- Nothing OS

Design Language:
- Dark mode only
- Matte black background
- Premium glassmorphism
- Soft shadows
- Subtle gradients
- Rounded corners
- Floating elements
- High-end Apple-quality animations
- Clean typography
- Minimal and futuristic
- Apple Design Award level quality

Avoid:
- Generic fintech dashboards
- Tables
- Statistics
- Analytics
- Bright colors
- Material Design appearance
- Business software look

==================================================
HOME SCREEN
==================================================

The entire app revolves around cards.

Top Section:
Title: CardVault
Subtitle: Your cards, one tap away

Top Right:
A floating glassmorphism container called:

"Active Island Card"

Purpose:
Represents the card currently pinned to Dynamic Island.

Empty State:
- "No card selected"
- "Drag a card here"

Selected State:
- Card icon
- Card title
- Active indicator
- Green glowing status dot

==================================================
CARD STACK
==================================================

Center of screen.

This is the main hero component.

Display a floating stack of premium cards.

Requirements:
- Top card fully visible
- Other cards partially visible underneath
- Cards overlap naturally
- Premium depth and shadows
- Floating effect

Interaction:
- Swipe left/right to move between cards
- Smooth spring animations
- Apple Wallet style movement

==================================================
CARD FRONT
==================================================

Each card front displays:

- Card title
- Card holder name
- Institution name
- Category
- Premium visual design

Library Access

==================================================
CARD BACK
==================================================

Tap card to flip.

Use realistic 3D flip animation.

Back side contains:

- Barcode
- QR code (optional)
- Card number
- Additional details

Example:

[ BARCODE ]

102306233

Barcode should be centered and large.

==================================================
DRAG AND DROP
==================================================

User can drag any card.

When dragging:
- Card enlarges slightly
- Background blurs
- Active Island zone glows

When dropped into Active Island zone:
- Card animates into the container
- Success animation
- Active indicator appears
- Card becomes the active Dynamic Island card

This interaction should feel magical and premium.
